# Prompt Tracker — desktop app

**Download:** [Releases → Latest](https://github.com/saquib34/prompt-tracker-releases/releases/latest)

| Your Mac | File |
|---|---|
| Apple Silicon (M1/M2/M3/M4) | `Prompt-Tracker-<version>-mac-arm64.dmg` |
| Intel | `Prompt-Tracker-<version>-mac-x64.dmg` |

Not sure which? Apple menu → About This Mac → "Chip: Apple M…" means Apple Silicon.

## Install
1. Open the `.dmg` and drag **Prompt Tracker** into **Applications**.
2. First launch: **right-click the app → Open → Open** (the app isn't notarized by Apple yet, so macOS asks once).
   If it says it "can't be opened", go to **System Settings → Privacy & Security → Open Anyway**.
3. Sign in with your email, or click the invite link you received.

## Updates
The app checks this page and tells you when a new version is out. Install the new `.dmg` over the old app; your sign-in and settings are kept.
